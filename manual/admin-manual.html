3. แดชบอร์ด

หน้าแรกหลังล็อกอิน เป็นทางลัดไปยังงานที่ทำบ่อย

→ เมนูซ้าย: แดชบอร์ด
  • คลิกการ์ด เช่น “โปรโมชัน” หรือ “แคตตาล็อก” เพื่อเปิดหน้าแก้ไขทันที
  • เหมาะสำหรับเริ่มงานเร็ว โดยไม่ต้องไล่หาในเมนูยาวๆ

4. ข้อมูลเว็บไซต์

→ ตั้งค่าเว็บ → ข้อมูลเว็บไซต์

แก้ชื่อเว็บ เบอร์โทร อีเมล ใบอนุญาต โลโก้ และข้อมูลติดต่อที่ใช้ทั่วทั้งไซต์

  1. เปิดเมนู ข้อมูลเว็บไซต์
  2. แก้ช่องที่ต้องการ เช่น ชื่อเว็บ / เบอร์โทร / อีเมล
  3. กดปุ่ม บันทึก สีส้มด้านล่าง
  4. เปิดหน้าเว็บจริงแล้วรีเฟรช (Ctrl+F5) เพื่อตรวจผล

5. หน้าแรก

→ ตั้งค่าเว็บ → หน้าแรก

จัดการส่วนต่างๆ บนหน้าแรก เช่น Hero, แผนแนะนำ, รีวิว, ทำไมต้องเลือกเรา

เคล็ดลับแก้ทีละส่วน แล้วกดบันทึก — ไม่จำเป็นต้องแก้ทุกช่องพร้อมกัน

6. สื่อ & รูปภาพ

→ ตั้งค่าเว็บ → สื่อ & รูปภาพ

อัปโหลดรูปที่ใช้ในเว็บ เช่น Hero, ใบอนุญาต, รูปสินค้า

  1. กดอัปโหลด / เลือกไฟล์รูป
  2. รอจนอัปโหลดเสร็จ
  3. คัดลอก path หรือเลือกใช้รูปจากหน้าแก้ไขอื่น ๆ
แนะนำใช้ไฟล์ JPG/PNG/WebP ขนาดไม่ใหญ่เกินไป เพื่อให้เว็บโหลดเร็ว

ปุ่ม รีเซ็ต CMS = ลบเฉพาะการแก้ไขเนื้อหา แล้วย้อนกลับค่าเดิม — ไม่ได้ลบแผนออกจากเว็บ

10. บทความ

→ เนื้อหา → บทความ
  1. กด + เพิ่มบทความ หรือปุ่ม แก้ไข ของบทความที่มีอยู่
  2. กรอกหัวข้อ slug รูปปก และเนื้อหาในตัวแก้ไข
  3. ตรวจ SEO title / description ถ้ามี
  4. กด บันทึก

13. สำรอง & กู้คืน

→ ระบบ → สำรอง & กู้คืน
  1. กดสร้างไฟล์สำรองก่อนแก้ข้อมูลสำคัญ
  2. ดาวน์โหลดเก็บไว้ในเครื่อง
  3. ถ้าต้องการย้อนกลับ ให้กู้คืนจากไฟล์สำรอง
แนะนำสำรองทุกครั้งก่อนลบหมวด / แผน / โปรโมชันจำนวนมาก

15. ข้อควรรู้สำคัญ

หลังบันทึกแล้วไม่เห็นผล รีเฟรชหน้าเว็บแรง ๆ (Ctrl+F5) หรือลองเปิดแบบไม่ระบุตัวตน
ดูผลที่เว็บไหน? ถ้าเข้าแอดมินที่ fwdagentthailand.com/admin/ ให้ดูผลที่ fwdagentthailand.com
GitHub Pages เป็นเว็บสำเนาแบบไฟล์นิ่ง ไม่ดึงข้อมูลสดจากแอดมินอัตโนมัติ
ปุ่มลบ vs รีเซ็ต ลบ/ซ่อน = ไม่โชว์บนเว็บ · รีเซ็ต CMS = ย้อนเนื้อหาที่แก้กลับค่าเดิม
หมวด “ทั้งหมด” ลบไม่ได้ เพราะเป็นหมวดพิเศษของระบบ
